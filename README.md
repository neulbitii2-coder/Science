# 📵 스미싱 문자 판별기

받은 한국어 문자메시지를 붙여넣으면 **나이브 베이즈**로 스미싱 위험도를 판별하는 단일 파일 웹앱입니다.
서버 없이 브라우저에서만 동작하며, 학습 데이터가 코드 안에 들어 있습니다.

## 실행

`index.html` 파일 하나만 있으면 됩니다. 더블클릭하거나 브라우저로 열면 끝입니다.

```bash
# 홈 화면 추가(PWA)·오프라인까지 쓰려면 http 로 띄우세요
python3 -m http.server 8000
# → http://localhost:8000
```

## 기능

| 기능 | 설명 |
|---|---|
| 판별 | 문자를 붙여넣고 **[판별하기]** → 위험도 게이지(0~100%)와 판정 |
| 근거 표시 | 위험 신호로 작용한 단어를 원문에 **빨간 하이라이트** + 기여도 칩 |
| TOP 10 | 학습 데이터 기준 **사기 신호 단어 TOP 10** 상시 표시 |
| 워드클라우드 | 스미싱 문자에서 신호가 강한 단어 90개를 크기·색으로 표현 |
| 점지도 | 학습 문자 1,000건을 2차원에 배치. 가로축 = 스미싱 신호 세기, 세로축 = 주성분 |
| 보관함 | 방문자가 입력한 스팸 문자를 자동 보관(localStorage) · CSV 내려받기 · 재학습 |
| 접근성 | 큰 글씨(보통/크게/아주 크게), 큰 버튼, 한국어 UI, 밝은/어두운 테마 |
| PWA | 매니페스트를 코드에서 생성 → 홈 화면에 추가하면 앱처럼 실행 |

## 판별 방식

**다항 나이브 베이즈**(라플라스 평활 α=0.25)를 자바스크립트로 직접 구현했습니다.
학습은 페이지가 열릴 때 자동으로 이뤄집니다.

한국어는 형태소 분석기 없이 다뤄야 하므로 세 가지 자질을 함께 씁니다.

1. **낱말 토큰** — `[가-힣]+`, 영문, 숫자
2. **글자 2-gram** — 조사·어미 변화를 흡수 (`환급금` → `환급`, `급금`)
3. **패턴 신호** — `§링크` `§전화번호` `§웹발신` `§금액` `§긴급` `§공짜미끼` `§개인정보` 등

위험도는 로그 오즈를 문장 길이로 보정한 시그모이드 값입니다.
`70% 이상 = 스미싱`, `40~70% = 주의`, `40% 미만 = 정상`.

정확도는 **5-겹 교차검증**으로 페이지에서 직접 계산해 보여줍니다.

## 데이터

| 파일 | 내용 |
|---|---|
| `data/messages_1000.csv` | 학습 데이터 1,000건 (스미싱 500 / 정상 500), 열: `문자내용`, `분류` |
| `data/generate_dataset.py` | 위 CSV 생성기 |
| `app/core.html` | 앱 본문 (데이터 자리는 `/*DATA_START*/` 마커) |
| `data/build.py` | `core.html` + CSV → `index.html` 빌드 |

> ⚠️ 원본 `메시지_데이터_최종본_1000.csv` 는 이 저장소에 포함되어 있지 않습니다.
> 여기 들어 있는 데이터는 Orange 워드클라우드에서 확인된 어휘·빈도(ㅁㅁ링크, `[Web발신]`,
> 안내, 확인, 알림, 신청, 무료, 고객님, 즉시, 이벤트 …)를 그대로 반영해 같은 규격으로 만든 것입니다.
> 템플릿에서 생성한 데이터라 교차검증 정확도가 실제보다 높게 나옵니다.
>
> **원본으로 바꾸려면** 앱 하단 **[내 데이터로 다시 학습]** 에서 CSV를 고르면 즉시 재학습됩니다.
> 영구 반영은 아래처럼 하세요.
> ```bash
> cp 메시지_데이터_최종본_1000.csv data/messages_1000.csv
> python3 data/build.py
> ```

## 개인정보

- 입력한 문자는 **서버로 전송되지 않습니다.** 판별·학습 모두 브라우저 안에서 끝납니다.
- 보관함은 **그 기기의 localStorage** 에만 저장되며 최대 500건까지 유지됩니다.
- 자동 보관은 체크박스로 끌 수 있고, **[전부 지우기]** 로 즉시 삭제됩니다.

## 빌드

```bash
python3 data/generate_dataset.py   # data/messages_1000.csv 생성

```
