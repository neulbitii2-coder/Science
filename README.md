# 📵 스미싱 문자 판별기

받은 한국어 문자메시지를 붙여넣으면 **나이브 베이즈**로 스미싱 위험도를 판별하는 단일 파일 웹앱입니다.
서버 없이 브라우저에서만 동작하며, 학습 데이터가 코드 안에 들어 있습니다.

처음 한 번은 저장소 설정에서 켜야 합니다. 워크플로 토큰에는 Pages 사이트를 새로 만들 권한이 없어

## 기능

| 기능 | 설명 |
|---|---|
| 판별 | 문자를 붙여넣고 **[판별하기]** → 위험도 게이지(0~100%)와 판정 |
| 근거 표시 | 위험 신호로 작용한 단어를 원문에 **빨간 하이라이트** + 기여도 칩 |
| TOP 10 | 학습 데이터 기준 **사기 신호 단어 TOP 10** 상시 표시 |
| 워드클라우드 | 스미싱 문자에서 신호가 강한 단어 90개를 크기·색으로 표현 |
| 점지도 | 학습 문자 1,000건을 2차원에 배치. 가로축 = 스미싱 신호 세기, 세로축 = 주성분 |
| 보관함 | 방문자가 입력한 스팸 문자를 자동 보관(localStorage) · CSV 내려받기 · 재학습 |
| 공유 수집함 | 방문자 신고를 구글 시트 한 장에 모음(선택). 전송 실패 시 대기열에 두었다 재시도 |
| 접근성 | 큰 글씨(보통/크게/아주 크게), 큰 버튼, 한국어 UI, 밝은/어두운 테마 |
| PWA | 매니페스트를 코드에서 생성 → 홈 화면에 추가하면 앱처럼 실행 |

## 판별 방식

**다항 나이브 베이즈**(라플라스 평활 α=0.25)를 자바스크립트로 직접 구현했습니다.
학습은 페이지가 열릴 때 자동으로 이뤄집니다.

한국어는 형태소 분석기 없이 다뤄야 하므로 세 가지 자질을 함께 씁니다.

1. **낱말 토큰** — `[가-힣]+`, 영문, 숫자
2. **글자 2-gram** — 조사·어미 변화를 흡수 (`환급금` → `환급`, `급금`)
3. **패턴 신호** — `§링크` `§전화번호` `§웹발신` `§금액` `§긴급` `§공짜미끼` `§개인정보` 등

위험도는 로그 오즈를 문장 길이로 보정한 시그모이드 값입니다.
`70% 이상 = 스미싱`, `40~70% = 주의`, `40% 미만 = 정상`.

정확도는 **5-겹 교차검증**으로 페이지에서 직접 계산해 보여줍니다.

## 공유 수집함 (방문자 신고를 한곳에 모으기)

기본 상태에서는 방문자가 신고한 문자가 **각자 브라우저에만** 쌓입니다.
한 장의 구글 시트로 모으려면 — 서버 없이 무료로 — 이렇게 하세요.

1. 구글 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. [`docs/apps-script/Code.gs`](docs/apps-script/Code.gs) 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱**, *실행 사용자*는 **나**, *액세스 권한*은 **모든 사용자** 로 배포합니다.
4. 나온 `https://script.google.com/macros/s/.../exec` 주소를 `data/collect_url.txt` 에 넣고
   ```bash
   python3 data/build.py && git commit -am "공유 수집함 연결" && git push
   ```

붙이고 나면 앱 보관함에 **[신고한 문자를 공유 수집함에도 보내기]** 체크박스와 전송 상태가 나타납니다.
빌드 스크립트는 `https://script.google.com/` 로 시작하는 주소만 받아들입니다.

## 개인정보

- 판별과 학습은 **전부 브라우저 안에서** 끝납니다. 인터넷으로 나가는 것은 공유 수집함에 보낼 때뿐입니다.
- 보관함은 **그 기기의 localStorage** 에만 저장되며 최대 500건까지 유지됩니다.
- 공유 수집함으로 보내는 항목은 **문자 내용 · 분류 · 위험도 · 시각** 넷뿐입니다.
  IP·브라우저 정보·쿠키는 앱이 수집하지 않습니다.
- 방문자는 체크박스 하나로 전송을 끌 수 있고, **[전부 지우기]** 로 자기 기록을 즉시 지울 수 있습니다.
- 공유 수집함을 켠다면, 방문자가 남의 개인정보가 담긴 문자를 그대로 올릴 수 있다는 점을 감안하세요.
  모인 시트는 공개하지 말고 분석 용도로만 쓰는 것을 권합니다.
